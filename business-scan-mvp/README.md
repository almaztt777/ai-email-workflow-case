# AI Business Scan MVP

Pre-sale 360° аудит компании: факты → денежные гипотезы → проверка → персональный заход.

## Уже работает
- публичный скан сайта: CTA, WhatsApp, формы, tracking, canonical, H1, JSON-LD, robots/sitemap;
- отдельные контуры: реклама, карты/отзывы, соцсети, mystery-shopping;
- карта 9 зон: привлечение, конверсия, продажи, CRM, операционка, удержание, репутация, аналитика, B2B;
- ранжирование коммерческих гипотез;
- генерация первого сообщения;
- разделение ФАКТ / ГИПОТЕЗА / НУЖНО ПРОВЕРИТЬ;
- optional AI-слой через OPENAI_API_KEY.

## Локально
Node.js 20+:
```bash
node local-server.js
```
Открыть http://localhost:3000.
